## Review Notes

- `Taggedby` is not derived from SQL `GROUP BY` by itself. The source of truth is the tag keys actually used when constructing emitted points.
- Collector-owned dimension tags should be listed in `Taggedby`; global host tags, election tags, and user-configured global tags should not be copied into every field.
- Point tag construction may use `AddTag`, `point.NewTags(...)`, tag maps, helper wrappers, or `point.KVs` construction. Each collector batch should inspect the actual construction path before editing metadata.
