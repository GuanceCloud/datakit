# Measurement Metadata Audit Matrix

Generated: 2026-04-29
Baseline commit: `f66dfd78cd`

This matrix tracks semantic and readability cleanup for `inputs.MeasurementInfo` metadata under `internal/plugins/inputs`.

The initial inventory is heuristic. It scanned non-test Go files for `&inputs.FieldInfo{...}` literals and flagged candidates by naming and metadata patterns. A candidate is not automatically a bug; each row still needs source tracing against SQL, Prometheus `HELP` / `TYPE`, API docs, or runtime samples before code changes.

> review: 这些指标的各种信息（单位/类型/指标说明等）主要是外部 AI 来读取，AI 会根据你提供的这些指标信息，做进一步的指标处理，比如构建 dashboard/故障分析/根因定位/疑难解答等，务必保证指标的各种信息准确和权威，不要胡乱编造。
